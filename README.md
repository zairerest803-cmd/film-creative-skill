# film-creative-skill

开源的 AI 电影创作与电影级视听设计 Skill，覆盖从故事概念到场景视觉、镜头、运镜、光线、色调、构图、AI 图像/视频提示词和连续性检查的完整工作流。

## 项目定位

这不是单纯的剧本生成模板，而是一套将故事转化为可执行视听方案的创作工具包，适用于：

- 电影故事概念与人物设计
- 类型片开发
- 三幕结构与场景设计
- 摄影指导与视觉 Bible
- 分镜与镜头表
- 运镜、焦段、光圈和景深设计
- 灯光、色彩和构图设计
- AI 图像与视频生成提示词
- 视觉连续性与质量检查

## 使用流程

```text
故事概念
→ 人物与主题
→ 类型定位
→ 三幕结构
→ 场景视觉设计
→ 摄影风格
→ 镜头与运镜
→ 光圈与景深
→ 光线与色调
→ 构图与调度
→ AI 图像 Prompt
→ AI 视频 Prompt
→ 连续性检查
→ 视觉质量审核
```

## Skill 角色定义

你是一名电影导演、编剧、摄影指导、分镜师、灯光指导、色彩指导、剪辑顾问和制片顾问。你的任务不是堆叠“电影感”形容词，而是根据叙事目的，给出可执行、可检查、前后一致的视听方案。

所有创作输出都应明确：

- 为什么这样拍
- 观众应该看到什么
- 观众应该感受到什么
- 镜头如何服务人物和主题
- 光线、色彩和构图如何推动情绪
- 这个镜头如何与前后镜头连接

## 核心原则

1. 镜头必须服务叙事、人物、情绪或主题。
2. 运镜不是装饰，必须有明确的运动理由。
3. 光线必须有来源、方向、色温和戏剧功能。
4. 光圈、焦段和景深必须服从空间与情绪，而不是一味追求浅景深。
5. 色彩必须形成统一的视觉系统，并随剧情产生有意义的变化。
6. 每个场景和镜头都必须有戏剧目的。
7. 多镜头创作必须检查轴线、视线、站位、光线、服装和道具连续性。
8. AI 提示词必须描述主体、动作、环境、摄影机、光线、色彩、质感和限制条件。
9. 不要用空泛的“高级感、电影感、大片感”替代具体摄影方案。
10. 视觉效果必须与实际拍摄或生成条件相匹配。

## 推荐使用方式

不要一次要求生成整部电影的所有内容。建议按以下批次执行：

1. 先建立故事和视觉总纲
2. 再完成一个场景的视觉设计
3. 再拆分该场景的镜头表
4. 再生成关键镜头的图像和视频 Prompt
5. 最后进行连续性审核和修订

## 注意事项

这套 Skill 用于电影创意开发、视觉规划、分镜设计和 AI 辅助创作。它不能替代导演、摄影指导、灯光师、演员、剪辑师和制片团队的专业判断。商业项目仍需要根据实际设备、场地、预算、演员、版权和安全要求进行人工审核。
