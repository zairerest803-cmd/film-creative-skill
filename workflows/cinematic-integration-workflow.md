# 电影视听整合工作流

## 目标

把故事、人物、场景、镜头、灯光、色彩、声音和 AI 生成提示词整合为一个可执行的电影视听方案。

## 阶段一：故事与视觉策略

1. 确定故事冲突和主题。
2. 确定每个主要人物的视觉识别元素。
3. 为故事建立视觉总纲。
4. 明确哪些视觉元素只在特定情绪或剧情阶段出现。

输出：

- 故事概念
- 主题
- 人物视觉标签
- 视觉 Bible
- 禁用项

## 阶段二：场景视觉开发

对每个场景先不要急着拆镜头，先确定：

- 场景目的
- 人物目标
- 权力关系
- 情绪变化
- 空间和时间
- 光源逻辑
- 色彩阶段
- 场景开头和结尾的视觉状态

## 阶段三：镜头策略

根据场景功能选择镜头：

- 环境建立：远景或大远景
- 关系互动：中景、中近景
- 内心变化：近景或特写
- 信息揭示：推、摇、拉或焦点转移
- 失控状态：手持、快速运动或不稳定构图
- 孤独和疏离：固定机位、拉远或负空间

先确定镜头策略，再填写焦段和光圈，不能反过来为了参数而设计镜头。

## 阶段四：单镜头拆解

每个镜头填写：

- 画面内容
- 戏剧目的
- 景别
- 机位
- 焦段
- 光圈和景深
- 对焦
- 运镜
- 构图
- 人物调度
- 光线
- 色彩
- 声音
- 前后镜头连接

## 阶段五：生成提示词

将镜头表转换为：

1. 静帧图像提示词
2. 视频动态提示词
3. 负面提示词
4. 角色和场景一致性约束

提示词必须保留原始镜头意图，不得只堆叠风格词。

## 阶段六：连续性审核

按以下顺序审核：

1. 人物身份、服装和道具
2. 空间位置和视线
3. 光线来源和阴影
4. 色调和曝光
5. 焦段和景深
6. 动作和摄影机运动
7. 场景时间与天气
8. 声音和剪辑连接

## 阶段七：导演级复核

问以下问题：

- 如果删掉这个镜头，观众会失去什么？
- 这个镜头是否比对白更有效？
- 镜头是否展示了人物关系变化？
- 光线是否说明人物处于什么状态？
- 色彩是否在故事中发生了有意义的变化？
- 运动是否来自人物、空间或情绪的需要？
- 这组镜头是否有起伏，而不是参数堆砌？

## 推荐执行顺序

不要一次要求模型直接输出整部作品。建议按以下批次执行：

1. 视觉总纲
2. 单个场景视觉方案
3. 单个场景镜头表
4. 关键镜头图像提示词
5. 关键镜头视频提示词
6. 连续性审核
7. 迭代修订

## 交付物

完成后应至少得到：

- 视觉 Bible
- 场景视觉方案
- 镜头表
- 灯光方案
- 色彩方案
- 图像 Prompt
- 视频 Prompt
- 负面 Prompt
- 连续性报告
- 修改清单
