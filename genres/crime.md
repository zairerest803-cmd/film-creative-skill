# 犯罪电影模板

## 1. 犯罪电影的核心承诺
犯罪电影的核心在于“规则被打破”与“代价”。

## 2. 常见结构
- 角色进入犯罪世界
- 契约、计划与目标设定
- 计划逐步出错
- 规则开始失控
- 选择变成愈发危险的局面
- 结局：生与死、自由与失去、罪与赎罪

## 3. 核心要素
- 个体目标必须足够强
- 角色必须有过往和现实限制
- 警方/黑社会/权力机构必须有压迫感
- 决定必须伴随后果

## 4. 电影视觉语言
- 画面通常偏冷、灰、潮湿、暗色
- 空间压迫感强
- 细节与表情比爆炸更重要
- 角色的光线要表现他们的拘谨和危险性

## 5. 重点检查
- 角色的选择是否有逻辑？
- 行动是否形成连锁反应？
- 结尾是否是真正的代价兑现，而不是简单“赢了”？
